pyql is a command line based tool that allows the user to interact with their local database

usage:
to see commands either launch the program with the -h argument ("python3 pyql.py -h) or launch the program and connect to a database, once connect type help
to use custom sql commands (SQLCMD) the tools must be launched in advanced mode ("python3 pyql.py -u")
you can test features on the included example ("pyql_example.db")
